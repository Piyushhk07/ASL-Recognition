System Overview

The ASL Vision pipeline runs entirely in the browser + a lightweight Python backend:

  • 1
    Camera Capture

    The browser accesses the device camera via getUserMedia and captures frames at ~15 fps.

  • 2
    MediaPipe Hands

    Each frame is sent to the Flask backend where MediaPipe extracts 21 hand landmarks (x, y, z) producing a 63-element feature vector.

  • 3
    ML Classification

    A trained Random Forest classifier maps the landmark vector to one of 26 ASL letter classes with a confidence score.

  • 4
    Visual Feedback

    The predicted letter and confidence are displayed in real-time; landmarks are overlaid on the video feed as a green skeleton.

  • 5
    Sentence Builder

    Detected letters can be accumulated into words and sentences using the on-screen sentence builder controls.

Quick Start
  1. Install dependencies — Run pip install -r requirements.txt in the project folder.
  2. (Optional) Train a real model — Download the Kaggle ASL Alphabet dataset and run python train_model.py --dataset path/to/asl_alphabet_train. Without this step, a synthetic demo model is used.
  3. Start the server — Run python app.py. The app will be available at http://localhost:5000.
  4. Go to Live Recognition — Click Live Recognition in the sidebar, click Start Camera, and show your hand to the camera.
  5. Build sentences — Hold each letter gesture steady for ~1 second, then use the Space / Backspace buttons to compose words.
