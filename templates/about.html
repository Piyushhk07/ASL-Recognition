About ASL Vision

Project overview, architecture, and acknowledgements

Project Description

ASL Vision is a real-time American Sign Language (ASL) gesture recognition system that uses computer vision and machine learning to classify hand gestures into ASL alphabet letters (A–Z) with low latency directly in the browser.

The system is designed to be accessible and easy to run: it requires no special hardware beyond a standard webcam, and runs entirely on a local Python server — no cloud services or paid APIs needed.

It is intended as an educational demonstration of how MediaPipe, scikit-learn, and a simple web frontend can be combined into a working end-to-end ML product.

Dataset & Model

The recommended training dataset is the Kaggle ASL Alphabet dataset by Akash, which contains approximately 87,000 images of 29 classes (A–Z plus space, delete, and nothing). This application uses only the 26 letter classes.

If the dataset is not available, train_model.py automatically generates synthetic hand landmark data so you can explore the interface without a real dataset. Predictions with the synthetic model are not meaningful for real-world use.

The classifier is a Random Forest with 200 estimators operating on the 63 landmark coordinates returned by MediaPipe. This is intentionally simple to keep training fast (minutes, not hours) while still demonstrating the end-to-end pipeline.

Limitations & Known Issues
  • Only static gestures are supported (no motion-based letters like J or Z).
  • Performance depends on lighting conditions and camera quality.
  • The synthetic demo model is not trained on real hand images — accuracy will be low until a real dataset is used.
  • Latency is higher than a native app due to base64 image transport over HTTP; a WebSocket implementation would improve this.
  • Only single-hand detection is currently supported.
